だいたい合っている。

細かい期間や技術スタックは職務経歴書に任せて、ここでは面白いところだけ書く。

## 観葉植物から始まった

新卒で入った会社の最初の仕事は、観葉植物の写真共有サービスだった。
エンジニアは自分ひとり。サーバーと iOS を両方やる。

そのあと突然、Facebook 広告のクリエイティブをクラウドソーシングするサービスに飛ばされた。
営業拠点はシンガポールとアメリカで、社内もサイトも全部英語。
観葉植物からいきなりグローバル広告の世界に放り込まれた感がある。

## ソシャゲでアジアを回る

次はアニメ IP の 2D オートバトル。日本・タイ・香港・台湾向け。
Unity でインゲームもアウトゲームもだいたい触って、Jenkins でビルドと画像圧縮を自動化したりしていた。
このへんが「ゲーム屋」っぽい時期のピーク。

そのあと漫画アプリ GANMA! で iOS・サーバー・Web をフルスタック。
リーダー不在のスクラムで、コードレビューと新人教育もやる、という感じ。

## フリーランスになってからのてんてん

2019 年から個人事業主。
以降はずっと、現場ごとに役割が変わる。

AI チャットボットの現場では、散らかった技術の掃除から入った。
TypeScript 導入、Hooks への乗り換え、分散しすぎたマイクロサービスをモノリスに戻す、みたいな地味で効く仕事。

ニュースアプリでは Push 通知基盤を一人で作り直した。
FCM トピック配信が遅延しまくっていたので内製したら、約 600 万件が 1 分未満になった。
今は 1000 万件超えてもだいたいそのまま動いているらしい、という話をあとから聞いた。

アパレルでは Stable Diffusion で服の柄を出したり、Blender と Three.js で衣服制作のワークフローをいじったりした。
サービスは終わった。

QuizKnock 系の会社では、小学生向け学習 Web ゲームのフロント周りを不定期でやっている。
報道系では気象庁の電文や L アラート、鉄道遅延のスクレイピングを API にした。
建設系では 360 度パノラマと BIM ビューワを Canvas の中で格闘した。

## 現場が消えることもある

動物病院向け電子カルテの現場に入ったときは、問い合わせと障害が四六時中飛ぶレガシーだった。
改善のために人が集まり始めた矢先、ランサムウェアの被害で組織ががらっと変わって離脱した。
現場ごと消えることもある、という学び。

ファンコミュニティの案件では、コレクションを 3DCG 上に飾るアプリをやる予定だった。
react-three-fiber でプロトタイプまで作って、開発中止。
だいたいこういうこともある。

## 20 年もののサイト

いまは Gaudiy。
買収した海外向けアニメ情報サイト MyAnimeList（運営もうすぐ 20 年）の移管とリニューアルに関わり、そこから派生した企業向けマーケティング支援「Gaudiy AI」のバックエンドをだいたい一人で見ている。

最近の趣味というか生存戦略は、実装を AI エージェントに寄せつつ、品質が壊れないよう CI とドキュメントで縛ること。
日次の AI レポート生成が 6 時間 15 分かかっていたのを、だいたい 6 分まで落としたりした。
数字だけ見ると派手だけど、中身は地味な並列化とキャッシュと不要処理の削除。

## 職歴に書いてない話

職務経歴書だと現場ごとの成果や役割が主役になって、普段なにを書いてるかが薄くなる。
Unity も TypeScript も、職歴の行としては目立たなくても普通に書いてる。昔の現場だけの話ではない。

## 結論らしきもの

観葉植物 → 英語の広告 → ソシャゲ → 漫画 → チャットボット → 通知基盤 → 生成 AI の服 → 学習ゲーム → 報道 API → BIM → 電子カルテ → ファンコミュニティ → MyAnimeList。

一貫性はない。
あるとすれば「崩れた現場に入って、とりあえず動くところまで持っていく」ことが多い、くらい。

鳥を二羽飼いながら、まだ立ち往生中。
